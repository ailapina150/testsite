# 🤖 AI Assistant — Лендинг с формой заявок, Telegram-ботом и Email-уведомлениями

## 📋 Описание проекта

Тестовое задание: создание двухэкранного лендинга с формой сбора заявок, интеграцией с Telegram-ботом для благодарности за регистрацию и автоматической отправкой уведомлений о новых заявках на почту.

---

## ✅ Что реализовано

### 1. Лендинг из 2 экранов
- **Экран 1 (Hero)** — яркий продающий экран с заголовком, описанием, статистикой и анимированной визуализацией AI.
- **Экран 2 (Форма)** — форма сбора заявок с полями: имя, телефон, email (опционально).

**Дизайн и UX-фишки:**
- 🎨 Современный градиентный дизайн с анимациями
- 📱 Полная адаптивность под мобильные устройства
- ⌨️ Маска ввода телефона в формате `+7 (999) 999-99-99`
- ✅ Валидация полей с понятными сообщениями об ошибках
- 🔄 Индикатор загрузки при отправке
- 🖱️ Плавный скролл к форме
- 📊 Анимированные счётчики статистики

### 2. Telegram-бот для благодарности
- 🤖 Бот **@AIMaster99Bot** создан через конструктор Unisender
- 💬 После отправки заявки пользователь автоматически перенаправляется в бота
- 🎉 Бот отправляет персонализированное сообщение "Спасибо за регистрацию"
- ⚙️ Бот работает 24/7 без необходимости в собственном хостинге

### 3. Email-уведомления о заявках
- 📧 Отправка через **EmailJS** (не требует собственного сервера)
- 📬 Письма приходят на **superhumansmm@yandex.ru**
- 📝 Формат письма полностью соответствует ТЗ:

```
Новая заявка с сайта https://testsite.smart-flow.workers.dev/

Автор: Анна Лапина

Данные из заявки:
Имя: {{имя пользователя}}
Телефон: {{телефон пользователя}}
Email: {{email пользователя}}
```

## 🚀 Как это работает

### Поток пользователя:
1. Пользователь открывает лендинг
2. Заполняет форму (имя, телефон, email)
3. Нажимает "Отправить заявку"
4. **EmailJS** отправляет уведомление на почту заказчика
5. Пользователь автоматически перенаправляется в Telegram-бот
6. Бот благодарит за регистрацию

---


### 1. Полностью клиентское решение без сервера
Большинство решений требуют собственного backend-сервера для отправки писем. Здесь используется **EmailJS**, который работает полностью на клиенте — не нужен сервер, не нужна оплата хостинга, всё работает из коробки.

### 2. Telegram-бот без хостинга
Вместо сложного Node.js-бота с polling (который требует постоянного сервера), использован **конструктор Manybot** — бот работает 24/7 бесплатно, без настройки серверов и деплоя.

### 3. Продуманный UX
- Маска телефона, которая сама форматирует номер
- Валидация с понятными подсказками
- Индикатор загрузки
- Плавные анимации и адаптивность
- Обработка клавиши Enter для быстрого перехода между полями

### 4. Надёжность и простота поддержки
- EmailJS — проверенный сервис с высокой доставляемостью писем
- Unisender — стабильный хостинг ботов
- Нет единой точки отказа (сервер не нужен)

### 5. Чистый и структурированный код
- Код разбит на логические секции с комментариями
- Понятные названия переменных и функций
- Легко поддерживать и расширять

### 6. Соответствие ТЗ на 100%
- ✅ 2 экрана с формой
- ✅ Telegram-бот с благодарностью
- ✅ Перенаправление в бота после заявки
- ✅ Email-уведомления с правильным форматом
- ✅ Указан автор (ФИО) и данные заявки

## 🔧 Настройка (для воспроизведения)

### EmailJS
1. Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com)
2. Создайте Email Service (Gmail)
3. Создайте Email Template с переменными `{{name}}`, `{{phone}}`, `{{email}}`
4. Укажите получателя `superhumansmm@yandex.ru`
5. В `script.js` подставьте свои Service ID, Template ID и Public Key

### Telegram-бот
1. Создайте бота через @BotFather
2. Подключите его к Manybot
3. Настройте приветствие на команду `/start`
